# Fouad El Sayed — Portfolio

Personal portfolio website for **Fouad El Sayed**, a Senior Mud Logger & Petroleum Geophysicist based in Qalyobia, Cairo, Egypt.

## Tech Stack
- **HTML5** semantic markup
- **CSS3** with custom properties (variables), dark/light themes, RTL support
- **Vanilla JavaScript** — no frameworks, no build step
- **Boxicons + Font Awesome** for icons
- **WebP** optimized images

## Features
- Bilingual (English / Arabic) with full RTL support
- Dark / Light theme toggle (persisted via `localStorage`)
- Animated hero with typewriter role swap
- AI-style chatbot (rule-based) for quick Q&A
- Responsive design (mobile sidebar, fluid grids)
- Accessibility: ARIA labels, keyboard nav, `prefers-reduced-motion` support
- SEO meta tags + Open Graph + Twitter cards
- PWA-ready (manifest.json + SVG favicon)

## Sections
1. Hero — intro, contact links, animated stats
2. About — bio + stats
3. Education (BSc Geophysics — Ain Shams University)
4. Experience (Senior Mud Logger, Mud Logger, Trainee Mud Logger)

6. Skills (Well-Site & Mud Logging, Software & Tools, Languages & Soft Skills)
